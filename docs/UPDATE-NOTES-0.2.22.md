# DiPlay 0.2.22 吉利兼容整合版

整合上游 `v0.2.22`（`28d6002`），保留本 fork 的吉利车机功能。
兼容包为 `io.dushu.car`，版本 `0.2.22-geely`，版本代码 `46`，沿用原签名配置，支持从代码 44/45 升级。
普通调试包为 `com.shihab.diplay.hudtest`，版本代码 `44`。

## 上游更新

- 修复无线热点接口选择、音乐播放加速和卡顿，改善 USB 重连和自动启动。
- 修复 USB 录音包过大导致的语音静音，增加通话原采样率实验选项。
- 改善双指触控、连接错误提示、诊断、设置备份，增加韩语和土耳其语。
- 增加 ECARX 轮速和挡位上报、特定领克仪表地图适配，以及桌面卡片窗口选项。
- 加固网络输入、USB 权限和远程 MFi 服务访问。

安装后的应用名称为 **DiPlay Geely**。

## 保留的吉利适配

- 仪表原车音乐卡片通过 OEM 广播接收封面 URI，并向原车媒体组件授予读图权限。
- 兼容包不设置可调试标记，保留可编辑侧边栏入口及原车固定组件名称。
- 保留方向盘按键、车辆桥接、导航投屏、音频路由和吉利独立热点通道。
- 桥接轮速启用时继续优先使用桥接来源；未启用时可使用上游 ECARX 来源。
- 保留后台连接的恢复任务所有权检查，同时支持开启蓝牙后立即重试。

应用内更新检查已改为 `Cy-xin/DiPlay`，避免继续读取原 fork 作者的发布渠道。
