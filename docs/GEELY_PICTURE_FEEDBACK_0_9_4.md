# 任务05：画面恢复后的失败反馈（0.9.4）

基线1bd4e068（0.9.3），工作区开始时干净；沿用codex/geely-return-picture。包名com.shihab.diplay，版本码136。仅执行任务05，未执行其他清单任务，未改AGENTS.md、系统应用、服务器或安装设备。

## 核查与实施

原流程仅在0/1/2秒请求画面，最后一次请求后没有观察或失败反馈。原判断用解码器计数“与baseline不同”作为新帧证据，计数重置存在歧义。

- 保持0/1/2秒三次请求，在第3秒做一次最终检查；没有新增画面请求、重连或轮询。
- 仍无新帧时回调一次，记录picture_restore_failed、reason、baseline/当前计数与会话代次。这里表示“暂未收到新画面”，不宣称连接已失败。
- 新增仅在需要时出现的提示，提供“重试画面”和“忽略”。重试只重启本轮画面恢复，不创建连接任务，不增加常驻返回/断开按钮。
- 新帧、Surface销毁、返回DiPlay、后台、断开、销毁或忽略时，清除提示并取消相关任务/订阅。
- Geely媒体Sink新增当前Surface送显序号和一次性帧事件：序号在Sink内跨解码器替换持续递增，仅计当前主解码器、真实显示Surface的送显，不计停车Surface及已退休解码器。事件可立即清理晚到画面后的提示，不靠后台检查。
- 观察者注册补查快照到注册之间到达的帧；旧Surface和旧轮次回调受身份及代次限制。底层发送到Surface不等于物理屏幕已显示，文案及报告保持这个边界。
- 保留Any身份令牌与原有请求合并语义；仅对显式手动重试清除旧轮次后重开。
- 无新增依赖、服务、权限、录音路径、连接协议变化。0.9.3麦克风识别修正保留。
