# 0.5.1 CarPlay纯画面

基线67537ebe（0.5.0）；分支codex/geely-session-retention，版本113。

用户已报告Redmi上0.5.0吉利图标、返回保连接与导航/音乐使用没有问题，要求去掉CarPlay右上角“返回DiPlay”“断开”两个覆盖按钮。本版仅删除该交互层与无用回调，CarPlay触摸直接交给既有SurfaceView，保留吉利OEM按钮、系统返回、DiPlay连接页主动断开及通知入口。不调整协议、连接生命周期、音频策略或认证。

0.5.0的代码检查、服务行为与核心库独立lint的既有问题见GEELY_SESSION_0_5_0.md。用户确认仅作为该设备和该次测试反馈，不扩展为吉利实车长期稳定性验证。
