# 0.6.2 CarPlay菜单栏位置

基线ed6ad9c0（0.6.1旋转修复），分支codex/geely-rotation-and-dock，版本117。

默认自动：竖屏底部、横屏左侧。旋转画布预声明两种方向各自的底部/驾驶员侧视口，使用原版updateViewArea切换，不重新建立连接。固定车机的普通画布也显式声明所选菜单边缘。

设置→音频与画面→CarPlay菜单栏位置提供自动/左侧/底部/右侧，保存后下次连接生效，不中断正在运行的会话。仅使用原版已知边缘值1（底部）与2（驾驶员侧）；右侧复用rightHandDrive=true，因此部分CarPlay面板也可能换边，不伪造第三个协议边缘值。

项目要求的检查、geely 37项及geely-core 5项单测、精简APK核验通过；模拟器大字号横/竖屏及RTL设置/弹窗截图通过。已安装Redmi，用户反馈“好了，没问题了”。0.6.1横屏清晰铺满有实际截图；0.6.2最终截图时用户已离开CarPlay，因此没有将该截图当作菜单位置证据。手动各位置、实车与长期稳定性不能由单次反馈和离线测试全部替代。核心库独立lint的既有问题见0.5.0记录。
