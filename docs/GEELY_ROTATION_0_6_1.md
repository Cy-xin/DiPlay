# 0.6.1 横竖屏旋转修复

基线b173b8c3（0.6.0），版本116。Redmi实际截图与解码日志显示横屏窗口2400×1080仍播放1350×3000竖屏流，前一版仅将旧流等比留边，无法令iPhone重新布局。

移植原版CarPlayRotation的硬件方形画布选择与turningAreas计算（使用平滑1920上限，硬件优先次序对齐现有播放器）。对可旋转手机、竖屏启动或已观察到方向变化的窗口声明横/竖视口；已知固定横屏KX11及Automotive不因传感器默认启用方形画布。复用原版showViewArea/updateViewArea，收到发送结果后更新当前视口；不重新配对或断开音频。父视口裁切方形SurfaceView，只展示活动区域，触摸仍按整张画布归一化。实际根窗口布局变化时重新适配，避免方向回调先于窗口布局的时序问题。

无法配置方形画布的竖屏设备提示先横屏连接，避免继续发送不可用竖屏画面。固定车机普通画布路径保留。旋转画布有额外编解码成本，采用原版平滑模式的1920上限，用户的高清/大小期望值可能受该上限限制，诊断显示最终请求画布。

项目规定检查、应用lint、35项geely单测、5项核心单测及精简APK检查通过。新增4项覆盖双方向声明、视口裁切、触摸映射和固定车机默认策略。0.6.1已安装到Redmi；用户完成切换后，实际横屏截图确认清晰铺满（0.6.1仍由iPhone自动安排菜单，底部菜单待0.6.2按用户要求显式声明）。触摸映射有离线回归，完整实机双方向与触摸验收不以截图替代。实车仍待验证。
