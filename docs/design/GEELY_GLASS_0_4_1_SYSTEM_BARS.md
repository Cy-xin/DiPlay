# 0.4.1 Redmi 顶部黑边修复

基线7553203a（0.4.0），分支codex/geely-liquid-glass。

Redmi Android13开启隐藏系统栏后，窗口frame为[0,80][1080,2400]，顶部打孔安全区域被系统留黑。并非Compose页面内距或状态栏背景颜色本身导致。

API30以上设置LAYOUT_IN_DISPLAY_CUTOUT_MODE_ALWAYS，允许背景延伸至打孔区域；Compose仍通过safeDrawing保护控件。状态栏/导航栏保持透明，并关闭系统额外对比度遮罩；系统栏隐藏开关及系统返回行为保持原样。启动主题也配置同样的打孔策略，避免首次布局裁切。

完成项目规定的完整单测/lint/构建，geely19项单测通过；既有沉浸式生命周期测试增加打孔策略与对比度遮罩断言。最小APK与认证资产检查通过。0.4.1 / 111已更新安装至Redmi，实际截图黑边消失，窗口frame为[0,0][1080,2400]，隐藏系统栏设置保留。没有改动连接与音视频代码；吉利车机与CarPlay实测回归尚未进行。关闭隐藏开关的真机状态仍需人工确认，离线测试已覆盖恢复路径。
