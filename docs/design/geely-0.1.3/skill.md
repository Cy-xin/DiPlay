# 吉利 CarPlay 连接页面的本地设计约束

- 避免整页滚动导致主操作和状态离开首屏；配置独立滚动。
- 避免按物理分辨率或固定车机尺寸排版，使用实际窗口 dp 和字体倍率，并响应窗口变化。
- 避免并列多个等权重大按钮：连接 / 取消为主，蓝牙与诊断为次。
- 避免统计卡、设备仪表、虚构阶段进度、装饰性品牌介绍。
- 不为精简版建立设置中心，仅折叠低频接口和配对设备选择。
- 不因调整布局丢失输入或建立第二个连接任务。
- 已连接时以 CarPlay 画面为主体，保留断开入口。
- 对比宽屏、窄屏、大字体与紧凑窗口截图；不能以编译或布局测试代替连接实测。

本约束来自人工审阅同一原生页面，不是 unslop 20 样本自动生成结果。
