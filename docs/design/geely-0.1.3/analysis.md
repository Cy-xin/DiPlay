# 本地界面检查与设计依据

用户选择仅在本地设计，不接入 Sleek。unslop 自动采样依赖未安装的 Claude CLI，未生成 20 份样本；以下是对已有原生页面的人工检查，不冒充自动采样结论。

检查三种实际截图条件：标准横屏、大字体横屏、紧凑横屏大字体。后两种初始视口无法同时看到主操作与状态；原页面有三种与主操作尺寸相近的次要按钮，层级竞争明显。样本是同一页面的三种布局条件，不能当作独立设计样本。

## 设计方案

- 颜色：底色 #172C32、控件 #243D43、正文 #F2F4EF、说明 #A7BAB6、分界 #456267、操作 #C9DEB0。
- 字体：Android 系统无衬线及中文回退，不下载字体。标题 26sp、选项和输入 20sp、说明与状态 16sp。
- 对齐：左对齐；连接状态与主操作固定底部，配置在独立区域滚动。宽窗口左右分栏；窄窗口或大字体上下排列。

宽：标题 / 蓝牙、诊断 → 左侧两种模式 | 右侧配置 → 状态 | 连接
窄：标题 / 蓝牙、诊断 → 横排两种模式 → 可滚动配置 → 状态 → 连接

## 自检修订

删除常见仪表盘的卡片网格、数据装饰和大段说明。不使用玻璃、渐变或自动动画。保留实际连接任务相关的控件。区别来自针对横屏触摸的固定操作区与按字体缩放选择断点，而非增加视觉装饰。

音频仅尝试把媒体起播阈值从 300ms 降到 200ms，保留原有 200ms 容量余量和重缓冲处理。iPhone 当前使用类型 102，而非 103；不以关闭 buffered audio 宣称改善。端到端延迟仍需实机比较，网络间隙可能导致断音。
