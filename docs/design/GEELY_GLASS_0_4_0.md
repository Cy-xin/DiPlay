# DiPlay Geely 0.4.0 玻璃界面

## 基线与范围

基线 a1002c1ed1c4edf851af1a8ca702e038c09bd0e7（0.3.1 日志版本）。按用户确认的 App Store 排版 / 冷灰蓝玻璃效果图实现原生 Compose 界面，不更换框架、不增加依赖。仅修改 ReceiverUi、ReceiverTheme 及版本号；连接、认证、音频、视频、触摸传输、日志上传和存储保持原有实现。

## 导航与交互

- 连接：两种模式，网络名称和密码，折叠高级网络接口，状态与连接/取消操作。
- 设置：连接（蓝牙、已配对手机）、音频与画面（缓冲、30/60帧）、外观（三种主题、隐藏系统栏）。宽窗口使用分组侧栏，窄窗口使用滚动分组列表，搜索跨设置分组。
- 诊断：操作记录说明、问题描述、服务器配对、上传/重试、诊断编号与本地记录。诊断入口从设置迁移至单独页，使用同一上传逻辑。
- 系统返回逐层关闭弹窗、返回连接页。连接时隐藏所有导航和背景，继续使用原 SurfaceView；仅保留断开入口。
- 120 帧与80ms仅出现在概念效果图，实际遵循当前协议支持的30/60帧及已有音频缓冲选项，不提供无效选项。

## 视觉与适配

品牌蓝 #0060C9；浅色背景冰蓝 #D9ECFC / #BBDCF6 / #E8F4FF，正文 #172434、辅助 #4B596C；深色背景 #172B46 / #0F1D30 / #244E72，正文 #EDF3FC、辅助 #B8C6DA。系统无衬线字体，标题24–30sp，正文14–16sp，辅助12–14sp。8dp栅格，页面20dp，卡片28dp，控件20dp，导航和主操作圆角胶囊，触控最小48dp。

玻璃仅取样本应用静态背景：API31+局部18dp模糊，API30不做实时背景模糊，直接重绘静态背景并叠加填充和细高光边框。浅色填充48%、深色74%，不模糊文字、不捕获系统或CarPlay画面。避免动画折射、多层实时捕获与新渲染依赖。主题保存仍为既有DataStore，颜色220ms过渡。

低高度窗口收起宣传标题，横屏配置并排；大字号允许切换单列并滚动，保持连接操作与导航可达。使用safeDrawing与imeInsets，表单错误提示、密码显隐、TalkBack角色及实时状态语义保留。OEM系统栏能否隐藏仍依赖原车支持。

## 验证与限制

完整Gradle检查、geely单测与lint、最小APK/认证资产检查及模拟器截图验证见交付目录。截图覆盖横竖屏、1.4字号、深色、音频弹窗、诊断和RTL。阿拉伯语环境仅验证镜像布局，当前应用文案仍沿用中文/英文，不宣称新增完整阿拉伯语翻译。

没有Android11模拟器镜像，API30静态降级经过代码检查，吉利车机实际效果和性能待实车确认。没有iPhone连接模拟器，不将UI测试当作CarPlay音视频回归通过。没有实测60/120fps或完整TalkBack人工朗读验证。
