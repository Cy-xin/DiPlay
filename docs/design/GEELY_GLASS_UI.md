# DiPlay Geely · Glass UI

## 设计方向

供车内横屏使用的简洁玻璃界面。主页保留连接手机这个唯一主要动作；设置按用户目标分类，工具页使用相同的颜色和控件。
CarPlay 视频、原车仪表和系统桌面内容不由此设计重绘。

## 色彩与字体

- 浅色背景：`#EDF1F7`；浅色面板：`#FAFCFF`。
- 深色背景：`#101216`；深色面板：`#20242B`。
- 日间强调色：`#005BBF`；夜间强调色：`#A1CBFF`。
- 使用 Android 原生 sans-serif / sans-serif-medium 字体，中文由系统字体回退；正文、说明、标题层级清晰，不引入外部字体依赖。

## 布局与材质

主页：左对齐标题与连接状态、无线主操作、右侧 USB 和设置快捷入口；小窗口自然纵向排列。
设置：宽屏固定分类栏与独立滚动内容；紧凑窗口保留原有分类导航，不把桌面宽度强行缩小。
面板使用 28dp 连续圆角，控件使用随高度调整的 20dp 连续圆角，最小点击尺寸沿用现有车机规范。
静态柔光背景、略透明面板、细边缘高光和低强度阴影形成层次。超椭圆路径只在尺寸或圆角变化时重算。
不采集屏幕进行实时模糊，不增加后台动画或绘制循环。

## 验证

检查深浅主题的文字对比度、Android 原生控件行为、完整项目 CI。
通过 Robolectric 原生图形渲染主页、分类设置、连接与备份页，并检查紧凑大字体和阿拉伯语 RTL 截图。
实车流畅性、触控和阳光下可读性仍需停车状态下验收。
