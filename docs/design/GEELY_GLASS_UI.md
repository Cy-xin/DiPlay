# DiPlay Geely · 双导航极简界面

## 参考与判断

本轮参考：用户指定的小红书笔记《这套UI，高级感到底来自哪里？》
https://xhslink.cn/o/2XofIVLGrG2

已查看笔记正文和前三张图片。参考其白灰画布、分组白色面板、黑色胶囊按钮、统一间距和少量绿色点缀。车机需要大触控目标和可读的中文，因此不复制手机模型上的微小文字、照片或纯图标导航。

此方案替换此前 Subdeck 配色及三导航布局。版本代码 49，应用名 DiPlay Geely，包名 io.dushu.car。

## 设计规范

- 画布 #F5F5F5、面板 #FFFFFF、主文字／主按钮 #171717、次文字 #69696E、次按钮 #F3F3F3；绿色只用于状态与 CarPlay 图标。
- Android sans-serif 字体，标题 26–36sp、入口 16–18sp、摘要 13–16sp；跟随用户字号。
- 以 8dp 为间距基准，面板内边距 24dp、区块间距 16dp、面板连续圆角 24dp。按钮圆角随实际高度收敛成胶囊。
- 面板不叠加装饰性渐变或阴影；底部导航使用很轻的悬浮阴影。
- 文字左对齐；宽屏三组并排，窄屏／超大字体依次纵向排列，页面可滚动。底部预留完整导航高度，避免最后一项被遮挡。

## 信息架构

一级导航仅有 CarPlay、设置。切换页不结束后台 CarPlay 会话。

CarPlay：左侧连接状态、连接／打开 CarPlay、选择 iPhone、USB；右侧为连接配置、车机热点设置和快捷设置。错误和权限引导仍紧邻连接动作。

设置总览：

1. 常用设置：连接、显示、音频、导航。连接管理手机／热点／自动启动；显示管理画面／系统栏；音频管理声音；导航管理位置与 HUD 引导。
2. 车机适配：车辆偏好入口，以及地图投屏、HUD／仪表布局、方向盘按键工具。工具也可在车辆偏好页打开。原有实验功能仍保留实验说明和默认开关。
3. 应用与支持：语言、关于、诊断、高级。诊断在高级之前；高级保持风险说明。

总览下方保留四项常用开关及连接向导，不为低频工具另设主导航。分类详情在宽屏显示固定分类侧栏，窄屏通过返回到总览切换。每个设置仍使用原分类和持久化，工具入口仅负责导航，不复制设置逻辑。

## 验证边界

构建前执行项目要求的全量测试、lint 与各模块构建；另检查双导航数量、车机工具启动目标、返回路径、大字体、紧凑和 RTL 原生渲染。截图来自测试宿主，非实车画面。物理车机的触控、可读性、热点跳转和连接回归仍需实车确认。

认证输入保留在外部构建目录；不把密钥、APK 或签名材料加入源码仓库。
