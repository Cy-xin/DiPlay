# DiPlay Geely · Subdeck-inspired UI

## 目标与参考

参考用户指定的 Subdeck 官方 App Store 截图：
https://apps.apple.com/cn/app/subdeck-%E8%AE%A2%E9%98%85%E7%AE%A1%E7%90%86/id6798927583

借鉴浅灰画布、黑色文字、绿色重点卡片、白色分组列表和底部悬浮导航。
以原生 Android 组件重新实现车机横屏布局；不复用 Subdeck 的商标、截图或图标资产。
预览包保持 `io.dushu.car`、应用名 DiPlay Geely，版本代码 48。

## 信息架构

主导航只有三个目的地，切换页面不结束后台 CarPlay 会话：

- CarPlay：连接状态和唯一主动作「连接手机」，同组放置选手机、USB 连接和连接问题处理；右侧为连接配置、打开热点设置和快捷设置。
- 车机：先显示连接配置、打开热点设置和快捷设置，再显示地图投屏、HUD／仪表布局、方向盘按键。地图进入完整屏幕选择与显示区域配置；HUD 和按键进入既有设置组件，保留开关、权限说明和返回路径。
- 设置：连接、显示、音频、导航和车辆偏好；低频的日志、高级、语言和关于仍在分类设置中。宽屏保留分类侧栏，小窗口改为纵向内容。

主页不再放营销标题或重复的大图标。工具入口不藏在高级列表末尾，故障处理不占据主要导航。
系统桌面入口、返回、搜索和主题切换采用带无障碍名称的图标按钮。

## 视觉规范

- 日间画布 `#F3F4F7`，面板 `#FFFFFF`，文字 `#151719`，主按钮 `#171A1E`，连接重点卡片为薄荷绿。
- 夜间画布 `#101113`，面板 `#1D1F23`，重点卡片改为深绿色，降低夜间亮度。
- 使用 Android sans-serif / sans-serif-medium，中文由系统字体回退，不引入外部字体依赖。
- 面板采用 28dp 连续圆角，控件共用随高度调整的圆角策略；分组间距统一为 20dp。
- 玻璃效果集中在底部导航和弹窗。常规内容采用安静的实色分组，弱化边框。
- 只有状态和主要操作使用强层级，次要说明使用灰色；不以装饰性数字、卡片堆叠制造信息。

## 实现与验收

超椭圆路径只在尺寸或圆角变化时重算。材质采用静态渐变和轻微透明，不采集屏幕做实时模糊，不增加绘制循环。
保留原有连接、认证、媒体、仪表和车辆控制逻辑。导航改变信息位置，不创建另一套设置存储。
底部为内容预留滚动空间，切换主题后在焦点恢复完成后恢复滚动位置。

自动化检查覆盖对比度、主导航与返回路径、设置交互、完整 CI，以及深浅色、紧凑大字体、RTL、工具页和弹窗的原生渲染截图。
本版尚需实车检查触控、阳光可读性、夜间亮度和运行流畅性。
