# DiPlay Geely 0.2.1：竖屏与信息密度

基于0.2.0提交0f3a7964，分支codex/geely-compose-coolblue。用户已反馈0.2.0连接及主题正常，同时指出缺少竖屏、文字过大。

## 修复

- 删除清单中的sensorLandscape，不再强制横屏。应用跟随宿主窗口和系统旋转规则；吉利车机仍可保持其正常横屏，手机可以竖屏。手机若锁定方向，应在系统中调整自动旋转，不由应用强制覆盖。
- 标题28sp改为22sp，模式及主按钮20sp改为16sp，说明/状态16sp改为14sp。输入框16sp。继续尊重系统fontScale，不强行压缩无障碍字号。
- 标准页面边距24dp改16dp；短窗口仍使用8dp。模式和主按钮最小高度64dp改56dp；其他触控目标仍不小于48dp。
- 横屏空间充足时分栏与并排网络字段；竖屏自动上下排列。固定底部操作与独立配置滚动保留。
- 新增清单回归，确保Activity方向是UNSPECIFIED，避免后续又强制横屏。

## 连接边界

连接引擎、认证、音频和触摸处理未改。CarPlay分辨率仍使用实际视频区域。连接中旋转导致真实显示尺寸改变时会结束旧会话并提示重新连接，避免沿用旧坐标。竖屏UI支持不等于已经验证iPhone能接受每种竖屏CarPlay分辨率；需用户重连实测。

主题、缓冲、帧率、网络和配对保持原值。包名com.shihab.diplay，显示名DiPlay Geely，版本0.2.1 / 106，仍使用API30最低和目标版本。

本版离线检查、模拟器横竖屏截图和手机安装结果随交付记录提供。吉利实车、不同输入法与高字体倍率仍需复测。
