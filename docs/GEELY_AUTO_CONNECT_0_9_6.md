# DiPlay Geely 0.9.6：打开应用自动连接

基线 ed95a5d8，沿用 codex/geely-return-picture，不修改协议、音视频、方向盘映射和连接释放机制。

## 使用

设置 → 连接 → 打开 DiPlay 自动连接。默认关闭，保存后下次打开生效。

- 每次从后台进入前台（包括首次启动）最多尝试一次；旋转、布局和 Surface 回调不会重复发起。
- 采用当前已保存的车机热点或同一局域网配置，复用现有手动连接流程及超时、取消、错误处理。
- 已连接、正在连接、释放中或正在测试音频时跳过，不重建会话。正在编辑设置或显示弹窗时也跳过。
- 配置、权限、蓝牙、网络未就绪时提示原因，本次打开不继续等待或轮询；准备好后手动点击连接，或重新进入应用。
- 手动取消或断开后，本次前台停留期间不再次自动连接。下次从后台打开仍按开关尝试。
- 不主动申请权限；首次仍通过手动连接授权。不会打开 Wi-Fi、热点、系统设置，不新增后台服务、监听器或定时轮询。
- 热点模式检查指定接口存在、启用且有有效地址；局域网模式检查存在 Wi-Fi 网络，不以互联网可访问性代替 CarPlay 连接成功。
- 自动连接的开始和跳过原因进入现有本地诊断日志，不记录密码。

## 验证边界

自动尝试策略与偏好保存、延迟生效、配置失败后不重复尝试均有自动检查。新增开关有大字号窄屏、横屏、RTL 截图检查。
实际车机自动首次连接、返回前台重连、取消后再次打开及网络关闭提示，仍需实车验收；离线检查不代表 CarPlay 实际连接成功。
