# DiPlay Geely 0.9.1：方向盘与播放体验

沿用 codex/geely-return-picture，基线91b51d79（0.9.0），包名com.shihab.diplay，版本码133。

## 日志问题的改动

- 传输关闭移出主线程，不排在可能仍阻塞的启动任务后。关闭AirPlay监听和会话先于可能较慢的发现服务清理。
- 等待8秒超时不再永久判定失败；保存一次完成回调，实际完成后释放会话锁并恢复连接入口。无后台轮询，尚未释放时仍拒绝第二个连接任务。保留各项清理开始/结束日志，避免旧会话代次过滤吞掉证据。
- 音频时钟动态测量目标上限为用户预缓冲加400ms无线突发余量，避免把已经积累的一两秒队列接受为正常目标。保留低PCM不加速、网络暂停不学习漂移和原有压缩队列保护；没有强行清空队列来伪造低延迟。
- 复用原有独立视频输出线程，解码输入处理与及时取出画面分开；原有可选厂商低延迟参数及其回退机制保持。日志中的decode字段包含内部等待，不能将其等同纯硬解时间，也不能承诺所有卡顿原因已消除。
- 首次连接慢主要来自蓝牙握手与iPhone等待，现有报告不足以安全缩短协议等待；本版没有通过减少握手超时冒险加速。

地图间歇停顿的补充诊断：保留超过2秒的新帧间隔（sourceGapMax）、距最近收帧/送显时间（sinceRx/sinceShown），无新帧期间仍沿用现有5秒统计。静态地图也可能无新帧，所以这些数据只用于区分来源，不能自动判定故障；送显表示提交Surface，不是物理屏幕测量。没有引入新的轮询。

## 方向盘

仅KX11机型、首个CarPlay视频帧显示成功后订阅吉利InputService，断开/取消/销毁时解除。原车系统应用保持启用，无Root、额外权限、辅助服务或新后台服务。
- 200087短按→下一首；200088短按→上一首；200085短按→播放/暂停。
- 200400（实车MODE键）长按→Siri；短按不转发，保留原车音源切换。
- 不处理raw按下/释放、holding、双击，也不绑定原车语音键200231，避免重复控制或与HiCar冲突。
- 通过原版控制器sendMediaButton/requestSiri发送，工作由原有控制线程执行。每次记录键码、动作及入队结果；入队成功不等于手机已完成动作。
- 实车已确认事件来源和键码；本版转发到iPhone、断开后不触发以及后台控制尚待实测。未加入用户未要求的任意按键学习界面。

## 音量与界面

导航音乐本地增益以250ms平滑下降到50%，播报结束500ms恢复。重叠导航、短时间再次播报从当前音量继续，电话/Siri仍立即让出音乐。系统或iPhone自行调整的音量不受本地动画保证。
车机主页移到连接页左上方，主要连接/取消/返回CarPlay操作移到横屏页左下方。竖屏保持全宽按钮；大字体窄屏连接方式改纵排。紧凑、宽屏和RTL的大字体原生截图由测试生成；这不代替车机触摸与性能实测。

## 验收范围

离线回归覆盖渐变、通话优先、校准目标限制、按键回调去重、关闭后丢弃输入、清理超时后的晚到完成及竞争条件，并执行项目完整CI命令、Geely检查和APK验证。最终统计与哈希见交付目录。
无新增运行时或测试依赖。认证文件仅从既有本地目录接入，不打印、不提交，含认证资产的APK不上传公开GitHub。
