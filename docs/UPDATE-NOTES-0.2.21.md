# DiPlay 0.2.21（吉利车机同步版）

本版本把上游 DiPlay 0.2.21 与 carlito12345/DiPlay 0.2.16 的吉利车机适配合并到一起，版本号仍为 0.2.21，versionCode 43，可直接覆盖安装吉利 0.2.16（versionCode 41）。

## 上游 0.2.21 的改进

- 修复 0.2.20 引入的音乐延迟：暂停、切歌和跳转重新与 iPhone 同步，音乐时钟校准不再积压。
- 有线 CarPlay 可自行恢复：iPhone 接受请求但未打开 CarPlay 时会重新尝试，断开后不再无限等待，已恢复的连接不会被旧重试拆掉。
- 旧车机没有系统 Opus 编码器时，使用麦克风不再导致 DiPlay 退出；通话或短暂打断后音乐可以恢复。
- 无线 CarPlay 会说明启动失败原因；比亚迪车机在 CarPlay 结束后把仪表交还原车，DiYou 桌面卡片不再导致退出。
- 支持 Android 7.0，新增意大利语，以及默认关闭的临时系统栏、黑色圆角、播放/暂停方控键、双击 Siri、车机热点导入、桌面悬浮球和原车音乐律动。
- 导航播报音量改为直接衰减导航音频，兼容忽略媒体音量的 DiLink 3.0 车机。

## 保留的吉利 0.2.16 功能

- 吉利 HUD／仪表投屏：投屏屏幕选择、内容缩放、三指切换和投屏编辑器。
- 原厂 CarPlay 音频通路、车辆音频输出模式、导航与媒体输出设备选择。
- 原厂热点连接（含 `eth0.3` 等非标准接口）、车机 SSID／密码和热点诊断。
- 吉利方控桥：方向盘按键、缩放、语音暂停／恢复，以及车辆扫描与转向控制测试。
- 吉利车标、车型回退、云端诊断报告中的 HUD／转向／车辆地图诊断段。

## 说明

- 车辆功能需要另装 Android 9 及以上版本的吉利车桥 APK。
- 本仓库的普通构建不包含 mFi 身份和证书；可安装的 CarPlay 发布包需要在构建环境提供 `DIPLAY_AUTH_ASSETS_DIR`，并使用发布签名。
- 已在本地通过单元测试；真车投屏、方控和原厂音频仍需装车验证。
