# 0.9.2 方向盘映射设置与测试

分支codex/geely-return-picture，基线036e7fc4（0.9.1）；包名com.shihab.diplay，版本码134。无新增依赖，无新增服务、权限、后台轮询或系统应用改动。

## 使用

在设置中选择“方向盘”（宽屏），或搜索“方向盘”（手机竖屏可直接搜索定位）。三颗实体键可分别指定：下一首、上一首、播放／暂停、不执行CarPlay操作。保存后立即生效，不断开连接；支持恢复吉利默认。

默认值依据本车实测：下一首键200087→下一首，上一首键200088→上一首，播放暂停键200085→播放暂停。物理键码固定为已确认的吉利代码，本版不是任意车型的按键学习器；设置调整的是这三颗键的目标动作。
MODE 200400的长按Siri不参与三键重映射，仍仅在CarPlay连接成功后执行；短按保持原车音源切换。原车语音键不变。
“不执行CarPlay操作”仅停止DiPlay转发该键，不拦截原车自己的行为。

## 两种测试

- 测试控制：CarPlay连接成功后可用，发送一次所选动作。页面只提示“已发送，请核对响应”；不会把入队当成控制成功。
- 检测实体按键：需要吉利车机，20秒后自动结束，也可手动停止。显示键码、短按/长按及映射结果；检测期间不转发任何按键给CarPlay，原车动作仍可能出现。离开此设置、退到后台或断开连接也会结束检测并释放临时监听。未连接时可临时订阅原车按键服务用于检测，但不会触发Siri或媒体控制。已连接时复用当前监听，避免双重注册；结束后恢复正常转发。

手机能够查看、保存映射；没有吉利输入服务时明确提示不能检测实体按键。手机上的控制测试需要该手机自身已经连接CarPlay。
